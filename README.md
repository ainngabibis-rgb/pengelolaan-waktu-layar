# ⏳ FokusDigital -  

Website edukasi dan pengelolaan waktu layar (*screen time*) untuk membantu pelajar mengurangi kecanduan gawai.

## 📋 Dokumentasi Pemanfaatan AI (Wajib Sesuai Kisi-Kisi)
- **Kebutuhan:** Membantu menyusun struktur kerangka HTML/CSS/JS serta merumuskan konten edukasi teknik Pomodoro.
- **Contoh Prompt:** *"Buatkan struktur website edukasi pengelolaan waktu layar untuk siswa SMA menggunakan HTML, CSS, dan JS beserta kalkulator screen time."*
- **Verifikasi & Kontribusi:** Kode yang dihasilkan AI telah diperiksa ulang, disesuaikan desainnya, diuji responsivitasnya pada layar ponsel maupun desktop, serta dihubungkan secara mandiri dengan Google Apps Script.
